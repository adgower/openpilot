# Navigator prediction pilot

Research interface, default disabled. This is a finite prediction-field A/B experiment, not a proven RPM or pulsing fix. Local replay cannot establish ECU response, comfort or road readiness. Installation, ARM/runtime checks and a separately reviewed loaded experiment remain separate steps.

`python -m openpilot.tools.navigator.prediction_pilot status` reads the current card session. `arm` requires `--enable-pilot --condition A` or `--condition B`; there is no force option or persistent enable. `cancel` withdraws authority without requiring fresh status. These commands operate on the current machine's Params and monotonic clock; they are not a remote-device transport. This local integration has not issued a permit on the Comma.

A request carries schema version 1, a unique trial ID, condition, current session and source IDs, issue timestamp, active duration and total wait budget. Card must acknowledge it within two seconds against fresh CAN, current Navigator Alpha coordination configuration, stationary Park, disengaged control and passive health. No request survives card restart. Reused IDs, busy replacements, cancelled/old requests and stale status are rejected. Manager clears all three transient permit/cancel/status keys.

After acknowledgment, the unchanged finite runner waits up to 30 seconds total (including delivery), requires 100 ms of continuously healthy engine-only eligibility and then runs for three seconds by default, five seconds maximum. Measured speed must remain between 3 m/s and 20 mph. A leaves bytes unchanged. B copies the existing bounded engine-request encoding into only the prediction field of message 390. Brake/precharge, engine request, target speed, PID/integral, release rules and safety limits remain unchanged.

Guard loss, driver override, fault, permission withdrawal, source change, lease expiry or cancellation terminates the trial; there is no automatic resume or A/B cycling. A new explicit permit must be acknowledged in Park. Full onroad events, selfdrive state and relevant Ford panda health are consumed; brief faults and falling permission/engagement edges are latched. Unknown or stale health denies the pilot.

The I/O worker owns Params, source hashing and JSONL audits under the sibling `navigator-pilot` directory of the normal log root. The controller callback has no Params, hashing or filesystem operations. Both audit queues are bounded; failed/stale I/O, audit backpressure or source invalidation preserves the original command and cancels the overlay. Source binding includes the current source files and control/safety configuration. Journals contain proposals; they are not CAN-send receipts or ECU acknowledgments. Cancellation/rejection events are retained separately from proposals, including suppressed proposals after concurrent revocation.
